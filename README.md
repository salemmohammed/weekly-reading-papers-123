##  Survey & Taxonomy

### Agentic Artificial Intelligence (AI): Architectures, Taxonomies, and Evaluation of Large Language Model Agents
**Authors:** Arunkumar V, Gangadharan G.R., Rajkumar Buyya  
**Venue:** arXiv  
**Paper:** [arxiv.org/abs/2601.12560](https://arxiv.org/abs/2601.12560)

> Comprehensive survey covering architectures, taxonomies, and evaluation methodologies for LLM-based agentic AI systems.

---

##  Agent Optimization & Prompting

### GEPA: Reflective Prompt Evolution Can Outperform Reinforcement Learning
**Authors:** Lakshya A Agrawal, Shangyin Tan, Dilara Soylu, Noah Ziems, Rishi Khare, Krista Opsahl-Ong, Arnav Singhvi, Herumb Shandilya, Michael J Ryan, Meng Jiang, Christopher Potts, Koushik Sen, Alexandros G. Dimakis, Ion Stoica, Dan Klein, Matei Zaharia, Omar Khattab  
**Venue:** ICLR 2026 — The Fourteenth International Conference on Learning Representations  
**Paper:** [arxiv.org/abs/2507.19457](https://arxiv.org/abs/2507.19457)

> Introduces GEPA, a reflective prompt evolution framework that achieves competitive or superior performance compared to reinforcement learning approaches for LLM agent optimization.

---

##  Planning & Tool Use

### In-the-Flow Agentic System Optimization for Effective Planning and Tool Use
**Authors:** Zhuofeng Li, Haoxiang Zhang, Seungju Han, Sheng Liu, Jianwen Xie, Yu Zhang, Yejin Choi, James Y Zou, Pan Lu  
**Venue:** ICLR 2026 — The Fourteenth International Conference on Learning Representations  
**Project:** [agentflow.stanford.edu](http://agentflow.stanford.edu/)

> Presents AgentFlow, a system for optimizing agentic workflows in-the-flow, improving planning quality and tool use effectiveness without requiring offline training.

### How Can Input Reformulation Improve Tool Usage Accuracy in a Complex Dynamic Environment? A Study on τ-bench
**Authors:** Venkatesh Mishra, Amir Saeidi, Satyam Raj, Mutsumi Nakamura, Jayanth Srinivasa, Gaowen Liu, Ali Payani, Chitta Baral  
**Paper:** [arxiv.org/abs/2508.20931](https://arxiv.org/abs/2508.20931)

> Studies input reformulation as a strategy to improve tool usage accuracy in complex dynamic environments using the τ-bench benchmark.

##  Benchmarks & Evaluation

### τ-bench: A Benchmark for Tool-Agent-User Interaction in Real-World Domains
**Authors:** Shunyu Yao, Noah Shinn, Pedram Razavi, Karthik Narasimhan  
**Paper:** [arxiv.org/abs/2406.12045](https://arxiv.org/abs/2406.12045)

> Introduces τ-bench, a benchmark designed to evaluate tool-agent-user interaction across realistic, multi-turn real-world domains.

##  Security & Compliance in Software Services

### Detection of Data Exposures in Software Services Using a Large Language Model
**Authors:** S. S. Yau, S. Goswami, V. Shrivastav, G. Sannidhi  
**Venue:** 2025 IEEE International Conference on Software Services Engineering (SSE), Helsinki, Finland  
**DOI:** [10.1109/SSE67621.2025.00020](https://doi.org/10.1109/SSE67621.2025.00020)  
**Pages:** 91–97

> Applies LLMs to detect data exposure vulnerabilities in software services, presenting findings from IEEE SSE 2025.

### Regulatory Compliance in Software Services Using Emerging Technologies
**Authors:** S. S. Yau, K. Pandya, S. Choudhary  
**Venue:** 2024 IEEE International Conference on Software Services Engineering (SSE), Shenzhen, China  
**DOI:** [10.1109/SSE62657.2024.00018](https://doi.org/10.1109/SSE62657.2024.00018)  
**Pages:** 36–42

> Explores the use of emerging technologies, including LLMs, for automating regulatory compliance checks in software services.
