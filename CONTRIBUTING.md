# Contributing

Thank you for your interest in contributing to this paper list!

## How to add a paper

1. **Fork** this repository
2. Edit `README.md` and add your paper under the appropriate section
3. Use this format:

```markdown
### [Paper Title]
**Authors:** [Full author list]
**Venue:** [Conference / Journal / arXiv, Year]
**Paper:** [Link]

> One-sentence summary of the paper's main contribution.
```

4. Open a **pull request** with a short description of what you added and why it belongs here

## Criteria for inclusion

- Directly relevant to agentic AI, LLM agents, tool use, agent evaluation, or related applied areas
- Peer-reviewed, workshop, or arXiv preprint is fine — include venue clearly
- Include a working link to the paper or project page

## Sections

| Section | Topics |
|---|---|
| Survey & Taxonomy | Overviews, taxonomies, position papers |
| Agent Optimization & Prompting | Prompt engineering, RLHF, prompt evolution |
| Planning & Tool Use | Planning, function calling, tool integration |
| Benchmarks & Evaluation | Datasets, evaluation frameworks |
| Security & Compliance | LLMs for software safety, compliance |
| Books | Practitioner-oriented books |

If a paper spans multiple sections, place it in the most relevant one.

## Style

- Use sentence case for all headings
- Keep summaries to one sentence
- List all authors (abbreviate only if list exceeds ~10 names)
